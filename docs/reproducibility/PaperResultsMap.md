# Paper Results Map

Use the root-level `PAPER_RESULTS_MAP.md` for the readable table and `manifests/paper_results_manifest.json` for the full machine-readable mapping.

The map covers every row currently present in the unified paper-results table and records:

- method name
- variant or protocol
- code entry
- config file
- original run directory
- lightweight summary file
- reproduction command
- full-dataset requirement
- external-code requirement

Lightweight summary tables live in `results_summaries/`.
